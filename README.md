# iur-lmh/.github — configuración y gobernanza

Repositorio central de configuración de la organización **IUR · Laboratorio de Movimiento
Humano**. No contiene código de producción: reúne el contexto institucional, las
plantillas comunitarias y las políticas que aplican al resto de los repositorios.

## Contenido

| Archivo / carpeta | Propósito |
|---|---|
| `MANIFEST.md` | Inventario de repositorios, módulos, roles y servicios |
| `CONTEXT.md` | Contexto institucional, restricciones y principios |
| `STACK_INFO.md` | Stack oficial y configuración recomendada |
| `docs/` | Arquitectura, modelo de datos, API, despliegue y roadmap |
| `profile/README.md` | README público de la organización |
| `ISSUE_TEMPLATE/` | Plantillas de bug, feature y nuevo dispositivo |
| `PULL_REQUEST_TEMPLATE.md` | Checklist de revisión |
| `SECURITY.md` | Política de reporte de vulnerabilidades |
| `CONTRIBUTING.md` | Guía de contribución |
| `CODE_OF_CONDUCT.md` | Código de conducta |
| `CODEOWNERS` | Responsables por defecto |

## Repositorios

- [labos-core](https://github.com/iur-lmh/labos-core) — API FastAPI.
- [labos-web](https://github.com/iur-lmh/labos-web) — Portal Next.js.
- [biomech-pipelines](https://github.com/iur-lmh/biomech-pipelines) — Parsing y datasets.

## Privacidad

Este repositorio **no contiene datos de pacientes**. Los ejemplos son sintéticos. Para
reportar un problema de seguridad, seguir [`SECURITY.md`](SECURITY.md) y no abrir un
issue público.
